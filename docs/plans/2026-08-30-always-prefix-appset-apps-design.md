# Always-Prefix ApplicationSet Apps Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Make every chart-app Application name cluster-prefixed (`{{.clusterName}}-{{.path.basename}}`) so `cilium` becomes `unraid-lab-cilium` and `oci-lab-cilium`, removing the asymmetric exception that hid the local cluster in the UI.

**Architecture:** Single change to `appset.yaml` template `metadata.name` from conditional `if eq oci-lab` to unconditional `{{.clusterName}}-{{.path.basename}}`. Add a repo rule that forbids unprefixed chart-app names, codified in `AGENTS.md` and as a `.claude/skills` check. Rely on `syscode.io/cluster` label (already added) and `resource.customLabels` for UI display; rename triggers Argo prune/create of old unprefixed Applications (same destination, no data loss — Helm release names unchanged).

**Tech Stack:** Argo CD ApplicationSet (Go templating), `appset.yaml`, `AGENTS.md`, `bootstrap/argocd-cm.yaml` (already has display label), `kubectl`/`omnictl` verification.
